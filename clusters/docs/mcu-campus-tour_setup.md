# 銘傳管理學院導覽・學生參與版：Google 試算表設定步驟

完成後，學生在網頁上按「加入校園」送出的資料會進到你的 Google 試算表。你在「通過」欄打勾，那位同學就會出現在所有人的地圖上（網頁每 5 分鐘重新讀一次名單）。

## 一、建立試算表與後台（約 5 分鐘）

1. 到 Google 雲端硬碟新增一份試算表，例如命名為「管院導覽學生名單」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 刪掉編輯器裡原本的內容，把同資料夾的 `學生參與版_AppsScript.gs` 整份貼上，按 **儲存**。
4. 右上角 **部署 → 新增部署作業**：
   - 類型選「**網頁應用程式**」
   - 說明：管院導覽名單
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 按「部署」，第一次會要求授權，用你的 Google 帳號同意即可（畫面若出現「未經驗證」，點「進階 → 前往（不安全）」，這是你自己寫的程式）。
6. 複製畫面上的「**網頁應用程式網址**」（以 `https://script.google.com/macros/s/…/exec` 結尾）。

## 二、把網址貼進網頁

1. 用記事本或 VS Code 打開 `銘傳管理學院_校園導覽_學生參與版.html`。
2. 搜尋 `const ROSTER_API=''`，把網址貼進引號裡：
   `const ROSTER_API='https://script.google.com/macros/s/……/exec';`
3. 存檔，上傳到你的 GitHub Pages（或系網）。

> 注意：在 claude.ai 的預覽或直接雙擊打開本機檔案時，可能連不上試算表，請以上傳後的網址測試。

## 三、日常審核

- 試算表「名單」分頁每一列是一位同學：送出時間、系所、姓名、介紹、外觀。
- **「通過」欄打勾 = 公開**；取消勾選 = 下架。
- 想刪除就直接刪掉那一列。
- 同學如果只改外表，審核結果會保留；改了名字、科系或介紹，會自動取消勾選，需要重新審核。
- 「備註」欄可以自己寫筆記，不會公開。

## 四、之後修改後台程式

改了 Apps Script 程式碼後，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址才會維持不變並套用新程式。
